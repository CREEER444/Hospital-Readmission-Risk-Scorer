## 🔄 Patient Journey

```
1. Doctor enters patient info
   ↓
2. Clicks "Predict Risk"
   ↓
3. Frontend validates data
   ↓
4. Sends HTTP request to API
   ↓
5. Backend processes features
   ↓
6. ML model makes prediction
   ↓
7. System calculates risk level
   ↓
8. Generates recommendations
   ↓
9. Returns JSON response
   ↓
10. Dashboard displays results
    ├─ Risk badge (color-coded)
    ├─ Risk meter (visual)
    ├─ Risk percentage (numeric)
    └─ Clinical recommendations
   ↓
11. Saves to history
```

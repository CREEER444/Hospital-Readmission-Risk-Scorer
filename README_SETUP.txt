SETUP STEPS

1. Put these files in project root:
   - train_model.py
   - hospital_data.csv

2. Install libraries:
   pip install pandas scikit-learn joblib

3. Train model:
   python train_model.py

4. Models will be saved in:
   models/readmission_model.pkl
   models/scaler.pkl

5. Add AI functions from:
   app_py_ai_functions.txt

6. Start backend:
   python app.py
